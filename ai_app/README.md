# Self-Learning AI Agent

Private AI web app with live internet search, persistent semantic memory, controlled auto-learning, PDF/DOCX/XLSX/TXT ingestion, and scheduled research.

The deployed service can start before an OpenAI API key is configured. Add OPENAI_API_KEY in Render Environment settings to activate chat, embeddings, file learning, and scheduled research.

Self-learning here means controlled persistent memory and scheduled research, not rewriting model weights.
